# Aiti Guru — Admin Panel

🔗 [Live Demo](https://aiti-guru-alpha.vercel.app/)

Тестовое задание. Административная панель с авторизацией и управлением товарами.

## Технологии

- **React 19** + **TypeScript**
- **Redux Toolkit** + **RTK Query** — управление состоянием и запросы к API
- **React Hook Form** + **Zod** — формы и валидация
- **React Router v7** — роутинг
- **Vite** — сборка
- **CSS Modules** — стилизация
- **Feature-Sliced Design (FSD)** — архитектура

## Функциональность

### Авторизация
- Вход по логину и паролю
- Опция «Запомнить меня» — сессия сохраняется после закрытия вкладки
- Без галочки — сессия живёт только до закрытия вкладки
- Silent refresh: просроченный access token обновляется автоматически без выхода пользователя
- Защищённые роуты — неавторизованный пользователь редиректится на `/login`

### Таблица товаров
- Сортировка по столбцам (название, бренд, SKU, оценка, цена)
- Поиск с debounce
- Пагинация
- Выбор строк через чекбоксы (включая «выбрать все»)
- Состояние таблицы (страница, сортировка, поиск) хранится в URL — сохраняется при перезагрузке и доступно по прямой ссылке
- Адаптивность: часть колонок скрывается на мобильных экранах

### Форма добавления товара
- Модальное окно с полями: название, бренд, категория, SKU, цена
- Валидация через Zod
- Toast-уведомление при успешном добавлении

## Архитектура

Проект организован по методологии **Feature-Sliced Design**:

```
src/
├── app/          # Инициализация приложения, роутер, store
├── pages/        # Страницы (LoginPage, ProductsPage)
├── widgets/      # Композиционные блоки (ProductsTable)
├── features/     # Пользовательские сценарии (login-form, add-product, products-search)
├── entities/     # Бизнес-сущности (product, session)
└── shared/       # Переиспользуемые утилиты и UI-компоненты
```

### Ключевые решения

**Хранение токена.** Access token хранится в памяти Redux. При включённой опции «Запомнить меня» токен дополнительно сохраняется в `localStorage` для восстановления сессии после перезагрузки страницы. HttpOnly cookie недоступны из-за ограничений CORS тестового API (dummyjson возвращает `Access-Control-Allow-Origin: *`).

**Auth events.** Для избежания нарушения слоёв FSD при обновлении токена используется паттерн событий — `baseQueryWithReauth` диспатчит экшены из `shared/api/authEvents`, а `authSlice` в `entities` подписывается на них через `extraReducers`.

**URL как источник истины.** Сортировка, поиск и пагинация хранятся в URL через `searchParams`, что обеспечивает воспроизводимость состояния по прямой ссылке.
